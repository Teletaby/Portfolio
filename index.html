Platform Overview

JSquared Cinema is an enterprise media streaming and entertainment discovery platform built on Next.js 14. Engineered with high-throughput Vercel edge caching and resilient API fallbacks to deliver instant movie catalog access without performance degradation.

IT & System Architecture

  • Edge CDN Caching: Static assets and frequent catalog queries are cached at global edge nodes with automated invalidation.
  • Resilient REST Handshake: TMDB API integration implements retry-backoff algorithms to prevent rate-limiting outages.
  • Client-Side Persistence: Lightweight state architecture stores user preferences and watchlists locally, eliminating cloud database overhead.
  • Media Optimization: Responsive image transcoding reduces mobile payload sizes by up to 60%.

IT Deployment Stack

Next.js 14, React, Tailwind CSS, TMDB Public API, Vercel Serverless & Edge Network.

System Overview

FallGuard is an automated computer vision safety monitoring system developed as part of Justin's Intelligent Systems specialization. It analyzes skeleton keypoints from camera feeds in real time using Google MediaPipe and classifies sequential human body motions through a Long Short-Term Memory (LSTM) recurrent neural network.

Key Technical Innovations

  • Privacy-Preserving Skeleton Tracking: Extracts 33 spatial body landmarks without storing raw video frames, safeguarding resident privacy while drastically minimizing bandwidth.
  • Sequence-Based LSTM Classifier: Accurately differentiates normal daily activities from accidental falls with 99.0% confidence.
  • Multi-Camera Real-Time Dashboard: Instant visual alerts, camera room switching, confidence logging, and admin notification dispatch.

Technologies Utilized

Python, Google MediaPipe, Skeleton-Based LSTM, TensorFlow / Keras, OpenCV, Real-time WebSockets.

System Overview

VitalPoint is a full-stack clinical management and patient scheduling solution built to streamline appointments, manage doctor rosters, and eliminate scheduling collisions across healthcare facilities.

Healthcare IT Architecture
